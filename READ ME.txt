A little tool I made with AI to automate mouse clicking locally on 64-bit Windows.

INSTALL

1. Download the latest release ZIP.
2. Extract the complete folder.
3. Double-click Installer.bat.
4. Press Y once to accept the Terms and bundled Tool License and approve setup.
5. Leave the setup window open until every check passes.
6. Double-click the Auto Clicker shortcut created in the folder.

Keep the full extracted folder path at 72 characters or fewer so Windows can install the private packages reliably.

USE

1. Choose the click speed, button, action, stop condition, and position.
2. Click the shortcut box and press a key combination to change it.
3. Press Start clicking or the saved keyboard shortcut.
4. Press the same shortcut to stop, or press F8 for the emergency stop.

One-click mode allows at most 500 clicks per second; double-click mode allows
at most 250 double-click actions per second. Actual delivery depends on
Windows, the target app, and the computer. Test a low rate first, especially
at a saved position. Random timing cannot exceed these caps. The activity
view retains the latest 500 lines.

SETUP DETAILS

Setup keeps official Python 3.14.7, PySide6-Essentials, settings, and app-specific files private to this folder. It does not require administrator access, change PATH, or install global Python packages. Downloaded runtime archives are verified before use.

Setup creates and validates a folder-local Auto Clicker shortcut that starts the app directly with this folder's private runtime. Run Installer.bat again to repair setup or after moving the complete folder. Saved clicking preferences are preserved.

PRIVACY AND REMOVAL

The app has no telemetry, analytics, advertisements, accounts, or runtime network requests. Preferences stay in this folder. Review setup.log before sharing because it can contain local folder paths.

To remove this tool, close it and delete the extracted folder. This removes its folder-local shortcut, private runtime, dependencies, settings, and app files.

TROUBLESHOOTING

If setup stops, the window immediately names the failed check and shows a
"How to fix it" instruction. The same guidance is saved in setup.log.
Correct the problem and run Installer.bat again. Before downloading large
components, setup checks the bundled app source and Windows shortcut support.
It compiles source before downloading app packages. Success is shown only
after dependencies, offline self-tests, and the shortcut all pass. Keep the
complete extracted folder together.

If a keyboard shortcut is reserved by Windows or another app, choose a
different combination. F8 is the fixed emergency stop while the keyboard
monitor is working. If that monitor fails, clicking stops and new jobs are
blocked. Restart the app to restore keyboard shortcuts.

OFFLINE REGRESSION CHECKS

Run .runtime\python\python.exe -I scripts\Test-AppSafety.py from this folder.
The suite uses fake mouse input and offscreen Qt; it never clicks the desktop.
Use --report PATH to save measurements as JSON. Timing budgets detect
regressions and do not guarantee performance on another computer.
