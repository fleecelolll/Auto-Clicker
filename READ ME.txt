AUTO CLICKER

A little tool I made with AI to automate mouse clicking locally on 64-bit Windows.

INSTALL

1. Download the latest release ZIP.
2. Extract the complete folder.
3. Double-click Installer.bat.
4. Press Y once to approve setup.
5. Leave the setup window open until every check passes.
6. Double-click the Auto Clicker shortcut created in the folder.

Keep the full extracted folder path at 72 characters or fewer so Windows can install the private packages reliably.

USE

1. Choose the click speed, button, action, stop condition, and position.
2. Click the shortcut box and press a key combination to change it.
3. Press Start clicking or the saved keyboard shortcut.
4. Press the same shortcut to stop, or press F8 for the emergency stop.

SETUP DETAILS

Setup keeps official Python 3.14.7, PySide6-Essentials, settings, and app-specific files private to this folder. It does not require administrator access, change PATH, or install global Python packages. Downloaded runtime archives are verified before use.

Setup creates and validates a normal Auto Clicker shortcut in this folder. Run Installer.bat again to repair setup or after moving the complete folder. Saved clicking preferences are preserved.

PRIVACY AND REMOVAL

The app has no telemetry, analytics, advertisements, accounts, or runtime network requests. Preferences stay in this folder. Review setup.log before sharing because it can contain local folder paths.

To remove this tool, close it and delete the extracted folder. The shared Fleece Tools .pyw launcher can be restored later with the helper in %LOCALAPPDATA%\Fleece Tools\Python Launcher after every Fleece Tool is closed.

TROUBLESHOOTING

If setup or the shortcut fails, review setup.log and run Installer.bat again. Success is shown only after the dependencies, offline self-tests, and shortcut all pass. Keep the complete extracted folder together.

If a keyboard shortcut is reserved by Windows or another app, choose a different combination. F8 always remains the emergency stop.
